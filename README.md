# Daily Tasks

A simple personal todo app: due dates, priority, tags, filtering and sorting. Single-user, no backend — all data is saved in the browser's `localStorage`.

## Run

```bash
npm install
npm run dev
```

Open the URL printed in the terminal (defaults to http://localhost:5173).

## Test

```bash
npm test
```

## Build

```bash
npm run build
npm run preview
```
